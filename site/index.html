What it does

A complete blue-team pipeline in one binary: parse, detect, correlate, score, explain — and only then, optionally, block.

Reads your real logs

Streaming parsers for auth.log / syslog, UFW, nginx & Apache, Docker and journald — including messy legacy formats like sshd(pam_unix). Malformed lines never crash a scan.

20 detection rules + Sigma

Brute force, password spraying, root logins, sudo abuse, port scans, service tampering and more — plus an importer that runs community Sigma rules with ReDoS-safe matching.

Incidents, not noise

Related alerts are correlated into incidents with a kill-chain timeline, so 300 failed logins and the one success that followed read as a single story.

Explained risk scores

Every alert carries a 0–100 score with the exact factors that produced it. ML anomaly detection and optional local-LLM triage are assistants — never silent judges.

Response with guardrails

Firewall blocking is off by default and Linux-only: allowlists, cooldowns, block budgets, TTL auto-expiry, approval mode, a full audit log and one-command rollback. It refuses to lock out your own gateway.

Reports & daily digest

HTML, JSON, CSV and Markdown reports from every scan, plus a plain-language daily digest. sentinel replay re-runs any historical log as if it were live.

How it works

One streaming pass, five stages. Arbitrarily large logs run in bounded memory.

1 Parse

Raw lines become structured events: time, IP, user, service.

2 Detect

Sliding-window rules + Sigma pack + ML anomaly pass.

3 Correlate

Alerts group into incidents along the kill chain.

4 Score

Explained 0–100 risk with threat-intel enrichment.

5 Respond

Report always; block only with rails, or on your approval.

⚠️

Beta. Detection is validated on real logs, but treat alerts as leads for a human — not verdicts. Slow, low-rate brute force is a known gap.

⚠️

Unsigned builds. Windows SmartScreen / macOS Gatekeeper may warn on first run (“More info → Run anyway”). Verify the SHA-256 checksum if in doubt.

⚠️

Blocking is Linux-only and off by default. Windows/macOS builds analyse logs and write reports; they never touch a firewall.
